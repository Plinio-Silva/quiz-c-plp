# Requisitos do Projeto — QUIZ em Linguagem C

Este documento reúne todos os requisitos obrigatórios definidos pelo professor Sergio Roberto Costa Vieira para o trabalho de PLP — Paradigma Imperativo.

---

## 🎯 Requisitos Funcionais

- O quiz deve possuir **dois temas** de conhecimentos gerais.
- O usuário deve escolher entre um tema e/ou outro.
- Cada tema deve conter **10 perguntas** com quatro alternativas (A, B, C, D).
- Cada pergunta deve ser apresentada com **temporizador de 30 segundos**.
- Se o usuário não responder dentro do tempo, a questão é considerada incorreta.
- A tela inicial deve conter uma **animação estilo Loading**.
- A interface deve possuir:
  - Fundo com uma cor
  - Texto com outra cor
  - Feedback visual:
    - Acerto → tela verde piscando 3 vezes
    - Erro → tela vermelha piscando 3 vezes
- Ao final das 10 perguntas, deve ser exibida uma tela com:
  - Quantidade de acertos
  - Quantidade de erros

---

## 🧱 Requisitos Técnicos

- Linguagem obrigatória: **C** (não aceitar `.cpp`).
- Uso obrigatório da biblioteca **conio.c**.
- Código deve ser modularizado:
  - Até **5 arquivos .c** (se necessário).
  - Cada pergunta deve ser uma **subrotina separada**.
  - Deve conter funções com e sem parâmetros.
- Código deve possuir:
  - Identação correta
  - Documentação semântica
  - Comentários explicativos
- Perguntas e respostas devem estar **centralizadas na tela**.
- Perguntas podem ser apresentadas em ordem aleatória (opcional).

---

## 📄 Regras de Entrega

- Trabalho individual ou em dupla.
- O arquivo fonte deve conter cabeçalho com identificação dos alunos.
- O projeto deve ser apresentado ao professor.
- Prazo de entrega: **25/09 (sexta)**.
